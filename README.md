# 🧭 バイブコーダー・クエスト

コードを1行も書かずに、**AIと一緒にWebサービスを作り、GitHubで管理し、サーバーに公開し、更新・メンテする**ところまでを学べる、完全初学者向けの学習ゲームです。LLMのAPIキーの扱い方(漏らさない・環境変数・利用上限)も、ミッションを通じて身につきます。

### 2つの学習ルート(ステージ3で選択)
- **🤖 Git連携AI**: GitHubとつなぐと、AIがファイル作成・コミット・PRまでやってくれる(有料プランが必要な場合あり)
- **💬 チャットAI + GitHubの画面**: 無料枠のチャットAIでコードを出してもらい、GitHubの画面にコピペしてコミット

選んだルート・APIサービス(Anthropic / OpenAI / Gemini)に合わせて、ミッションの手順・プロンプト・キー名が自動で切り替わります。

### ゲームの種類
よみもの / クイズ / ならべかえ / 用語マッチ / 仕分け / 間違い探し / 選択 / **ミッション(実作業)**。
ミッションはGitHubの公開APIで自動チェックされます(うまくいかない時は自己申告で進めます)。
右上の **❓ヘルプ** に、用語集・困った時の対処(FAQ)・AIへの伝え方テンプレがあります。

## 先生(管理者)向け: 共有と進捗の把握(すべて無料・サーバー不要)

### 1. 公開する(GitHub Pages)
1. このリポジトリを **Public** にする
2. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
3. `main` にマージすると `.github/workflows/pages.yml` が自動で公開します
4. 公開URL `https://<ユーザー名>.github.io/<リポジトリ名>/` を学習者に共有

> 無料プランのGitHub Pagesは Public リポジトリが対象です(条件はGitHubの公式ドキュメントで確認してください)。

### 2. 進捗を把握する
- 学習者が **「📤 進捗」→「進捗を送る」** を押すと、このリポジトリに **Issue** が作られます(GitHubアカウントが必要。ステージ2で全員作ります)。
- `dashboard.html`(`…/dashboard.html`)を開くと、全員の最新進捗(どのステップまで進んだか、自動確認/自己申告、いま止まっている場所)が一覧になります。
- Issueには ニックネーム・XP・ステップ達成状況 しか含まれません。**APIキーなどの秘密は一切扱いません。**

### 注意
- 進捗は学習者の自己申告ベースです(Issueは誰でも書けます)。厳密な採点には向きません。
- Issueは公開されます。学習者には本名でなくニックネームを使うよう案内してください。
- GitHub APIの未認証アクセスには回数制限があります(ダッシュボードの閲覧程度なら問題ありません)。
- 学習者が増えて、よりリッチな管理(ログイン・個別フィードバック等)が必要になったら、Supabase や Firebase の無料枠、または Googleフォームなどへの移行も検討できます。

## ローカルで試す

```
python3 -m http.server 8000
# http://localhost:8000 を開く
```

ビルド不要の静的サイトです(HTML / CSS / JavaScript のみ)。

## 教材を編集する

`js/content.js` を編集すると、ステージ・クイズ・ミッションを追加・修正できます。ステップの `type` は `cards / quiz / order / match / sort / spot / choose / setup / mission`。文章中の `{{ENV}}` `{{PROVIDER}}` `{{GIT}}` `{{PR}}` `{{USER}}` は選択に応じて自動で置き換わり、`todo` / `prompts` / `tips` の `only` で出し分けできます。ヘルプの中身は `js/help.js` です。

## 構成

```
index.html        ゲーム本体
dashboard.html    先生用ダッシュボード
css/style.css
js/config.js      進捗送り先リポジトリの判定
js/content.js     教材データ
js/help.js        ヘルプ(用語集・FAQ・テンプレ)
js/state.js       進捗保存(localStorage)・XP計算
js/verify.js      GitHub公開APIによるミッション自動チェック
js/games.js       各ミニゲーム/ミッション画面
js/app.js         ルーティング・ホーム・進捗共有
```
